# Autonomous: project lessons

This project's own lessons, read together with the team lessons in the `agent-team` skill. The
Auditor is the only writer: lessons arrive in PR bodies ("Lesson:") and messages, and go in here
after the merge. One line each: the rule, then the bug, PR or moment it came from. At each release's
end, lessons that would help any project are promoted to the team file.
